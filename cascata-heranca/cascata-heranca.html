Cascata e herança são as regras básicas do CSS para decidir qual estilo aparece na tela. A cascata resolve conflitos de regras, a especificidade mede o peso dos seletores, e a herança passa valores do elemento pai para o filho.

O que é a Cascata?É o algoritmo do navegador que decide qual regra vence quando há conflitos.Segue a ordem de origem: se duas regras têm o mesmo peso, a que estiver por último no código vence.Usa o nível de importância (!important) e a especificidade (IDs ganham de classes, que ganham de tags) para definir prioridades.

O que é a Herança?É quando um elemento filho herda automaticamente propriedades de estilo do elemento pai.Propriedades de texto como color e font-family são herdadas por padrão.Propriedades de caixa como border, margin e padding não são herdadas para evitar um visual bagunçado.Você pode controlar isso com palavras como inherit (para forçar a herança) ou initial (para usar o padrão).
